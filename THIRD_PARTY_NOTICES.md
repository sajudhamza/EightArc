# Third-party visual component

The animated border in `components/ui/BorderBeam.tsx` adapts the structure and CSS motion-path technique of Magic UI's Border Beam component for this project's Tailwind 3 setup. It uses CSS animation instead of the Motion dependency and respects reduced-motion preferences.

- Source: https://github.com/magicuidesign/magicui/blob/main/apps/www/registry/magicui/border-beam.tsx
- Component documentation: https://magicui.design/docs/components/border-beam
- License: MIT; complete notice retained in `components/ui/MAGIC-UI-LICENSE.txt`.

The neural network illustration and all interactive service examples are original SVG/CSS/React implementations. Demo data is illustrative and does not represent client results. No paid template or external AI API is required.
